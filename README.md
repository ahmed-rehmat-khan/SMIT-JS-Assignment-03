### Project Overview

This project contains 20 JavaScript questions covering Sections A–E of the SMIT Batch 22 Assignment 03. Each question focuses on fundamental JavaScript concepts including loops, arrays, conditional statements, Boolean flags, and nested loops. The assignment is designed for beginners following Chapters 15–20 of the reference book.

### Assignment Objectives

- Practice using `for` loops for iteration and counting
- Learn to work with arrays using loop-based logic
- Understand Boolean flags for search and control flow
- Implement nested loops for pattern generation
- Solve real-world problems using JavaScript arrays and conditions
- Develop problem-solving skills without relying on advanced array methods

### Learning Outcomes

After completing this assignment, students will be able to:

1. Use `for` loops to count, iterate, and generate sequences
2. Use nested loops for patterns and multi-dimensional iteration
3. Implement Boolean flags for search and validation logic
4. Process arrays using basic loop and condition logic (no prohibited methods)
5. Calculate sums, averages, and filters using accumulator variables
6. Build multiplication tables and comparison logic
7. Analyze data and produce meaningful results (pass/fail, highest, average)
8. Create beginner-friendly programs with readable output

### Technologies Used

### Assignment Rules

1. Use `for` loops wherever iteration is required — no `forEach()`, `map()`, `filter()`, or `reduce()`
2. Use arrays where appropriate — provide exact values as specified in each question
3. Use conditional statements (`if`, `else`) where appropriate
4. Use `prompt()` for all user input requirements
5. Display output using `console.log()`, `alert()`, or `document.write()`
6. **Do not use:** `map()`, `filter()`, `reduce()`, `forEach()`, `sort()`, `reverse()`, `includes()`, `indexOf()`
7. **Do not use:** Functions, objects, or DOM manipulation
8. Use `break` with Boolean flags where specified
9. Use `push()` to add elements to arrays
10. Use meaningful variable names and proper indentation
11. Do not use `Math.max()`, `Math.min()`, or `sort()` for ranking/comparison tasks
12. Do not use `Set` for deduplication
