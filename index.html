Assignment Description

This assignment covers 20 questions on JavaScript arrays, loops, flags, and problem solving. Click a question number below to run its program. Each question runs independently.

Questions

  1. - Counting Generator: Print numbers from 1 to 100 using a for loop
  2. - Reverse Counting: Print numbers from 50 down to 1 using a reverse loop
  3. - Even & Odd Number Generator: Print even and odd numbers separately between 1 and 50
  4. - Multiplication Table: Ask user for a number and generate its multiplication table from 1 to 10
  5. - Sum of Natural Numbers: Ask user for N and calculate sum from 1 to N
  6. - Display Array Elements: Display eight student names with position numbers
  7. - Find Largest & Smallest: Find largest and smallest in [45, 12, 89, 3, 67, 22, 91, 10]
  8. - Reverse an Array: Display fruits array in reverse order
  9. - Filter Passing Students: Filter marks >= 50 from [85, 42, 67, 30, 90, 55, 25, 78]
  10. - Sum & Average of Array: Calculate total and average of [1200, 850, 430, 1600, 990]
  11. - Student Name Search: Search for a name in ["Ali", "Ahmed", "Sara", "Hamza", "Ayesha"]
  12. - Find a Number: Search for a number in [10, 25, 40, 55, 70, 85, 100] and show its index
  13. - Filter Numbers: Separate positive, negative, and zero from [12, -5, 0, 18, -9, 25, 0, -3, 40]
  14. - Remove Duplicate Numbers: Create unique array from [10, 20, 10, 30, 20, 40, 30, 50]
  15. - Star Triangle: Print nested star triangle pattern
  16. - Reverse Star Triangle: Print reverse star triangle pattern
  17. - Number Triangle: Print number triangle 1, 12, 123, 1234, 12345
  18. - Multiplication Table Grid: Generate tables from 2 to 5
  19. - Student Result Analyzer: Analyze student marks and calculate results
  20. - Mini Shopping Cart: Calculate bill with discount for selected product
